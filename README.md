# 🌐 Trust Net — Interactive Login Page

A modern, futuristic login page designed around the concept of **digital identity and secure connections**.

The main highlight of the interface is the **interactive glowing orb** behind the login card. Move your cursor around the orb to interact with it and watch it respond with a dynamic rotating effect.

## ✨ Features

- 🌌 Futuristic dark UI
- 🔵 Interactive glowing orb
- 🖱️ Cursor-based orb interaction
- 🔄 Dynamic rotation effect
- 🪟 Glassmorphism login card
- 📧 Email input field
- 🔒 Password input with visibility toggle
- 🌐 Social login buttons
- 📱 Responsive design
- ✨ Smooth animations and transitions
- 🎨 Modern neon blue/purple visual effects

## 🎯 Concept

The design is based on the idea of a **digital trust network**.

The glowing circular orb represents a secure digital network, while the login interface represents the user's connection to that network.

The orb reacts to the user's cursor to make the interface feel more dynamic and interactive instead of being a static login page.
